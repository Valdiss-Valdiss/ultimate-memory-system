# validate/ — скрипты проверки целевого состояния

Философия: не «шаги установщика», а проверка того, что система соответствует
целевому состоянию. Запускай после каждого изменения; красные пункты → рунбуки.

## validate_vps.py

Проверки сервера (запуск на сервере):
- docker active, контейнеры стека Up, аномальные рестарты;
- CouchDB: doc_count > 0, doc_del_count == 0;
- CLI-цикл: сервис active, лог без ошибок, зеркальные циклы завершаются;
- зеркало: непустое, живое;
- indexer: без ошибок;
- load/disk.

```bash
python3 validate_vps.py --db-user <user> --db-pass <pass> \
  [--db-name <hash>] [--mirror-dir /srv/memory-system/vault/memory-ai]
```

## validate_pc.py

Проверки ПК (Windows, запуск от пользователя):
- Obsidian запущен (или предупреждение);
- запланированная часовая задача включена;
- floodguard: маркер охлаждения истёк/отсутствует;
- один python-процесс конвейера (не два!);
- питание: sleep = 0, unattended sleep = 0 (Modern Standby);
- vault существует, число .md > 0;
- stderr-файлы фоновых процессов не содержат трейсбеков за сегодня.

```bat
py -3 validate_pc.py
```

## Коды выхода

0 — всё зелёное; N — число красных пунктов (для скриптов).
