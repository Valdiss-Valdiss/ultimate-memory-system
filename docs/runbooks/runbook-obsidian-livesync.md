# Runbook — Obsidian LiveSync (vault, E2E, устройства)

## Целевое состояние

- Vault синхронизирован со всеми устройствами через CouchDB;
- E2E-шифрование включено; passphrase ТОЛЬКО на устройствах;
- Deletion Propagation настроен (предпочтительно: в корзину);
- Настроены тогглы: sync on start/save/file-open — с пониманием, что открытие
  Obsidian = немедленный синк.

## Установка (агент делает с юзером)

1. Obsidian → Community plugins → **Self-hosted LiveSync** (obsidian-livesync).
2. Настройка через мастер: тип «CouchDB», URL — домен сервера (Caddy/реверс-прокси
   с HTTPS обязателен), логин/пароль — юзер CouchDB с правами на базу.
3. **E2E encryption: ON**. Парольная фраза: длинная, записана в менеджер паролей.
   Правило: passphrase никогда не на сервере.
4. Первый синк: «Fetch from server» (если сервер уже с данными) или «Send» (если
   vault на устройстве — источник истины).
5. Другие устройства: сначала создать vault, поставить плагин, затем
   **Delete local database → Fetch from remote** (не «Overwrite server data»!).

## После ребилда сервера / отката снапшота — re-setup ВСЕХ устройств

- Контрольная точка синка привязана к инстансу сервера → после восстановления
  из снапшота у каждого устройства слетает чекпоинт → «Репликация» пытается
  залить ВЕСЬ локальный граф (100k+ чанков, часы).
- Правильное действие: на каждом устройстве Delete local database → Fetch from
  remote (~15–20 мин). Порядок: ПК первым (источник правды), телефон последним.
- Если телефон был единственным донором свежих данных (офлайн, когда сервер
  деградировал) — СНАЧАЛА дай ему выгрузить патчи (обычный синк), только потом re-setup.

## Диалоги плагина — что означает

| Диалог | Безопасно? | Действие |
|---|---|---|
| «Server database is reset… Fetch?» | почти всегда да | подтверждай (получишь серверную копию) |
| «Overwrite Server Data with This Device's Files» | ОПАСНО | только осознанно, после инцидента восстановления (сотрёт серверное состояние локальной копией) |
| «Conflicts found: keep both / server / local» | да | «keep both» безопаснее; разбирать после |

## Deletion Propagation

- Рекомендуется «Delete files on other devices: Move to Obsidian trash».
- «Propagate immediately» — для опытных (удаление летит на все устройства мгновенно).

## Контрольные точки для агента

- После настройки: тестовая заметка с ПК → появится в CouchDB и на телефоне;
- Удаление тестовой заметки → исчезло везде (или в корзинах);
- Число заметок vault == число .md в зеркале сервера (± служебные).

## Известные грабли

- **Modern Standby на Windows**: засыпание рвёт сеть → Telegram-сессии и синк падают.
  Лечение: runbook-windows-quirks.md (сон отключить, ноутбук в розетку).
- **Индексная БД плагина (IndexedDB)**: хранит и логи. Перед аварийными остановками
  Obsidian/удалением БД плагина — скопировать `%APPDATA%\obsidian\IndexedDB`.
- При «database is locked» на CouchDB — проверить, что не открыты ДВА устройства
  в момент перестроения зеркала; подождать цикл CLI.
