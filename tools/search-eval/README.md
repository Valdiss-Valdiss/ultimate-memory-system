# tools/search-eval — замер качества поиска на своём эталоне

Методика — `docs/runbooks/runbook-search.md` («Правило: любую правку поиска — сначала замер»).

```bash
python eval_search.py example_grades.json example_runs.json --base current
```

- `example_grades.json` — разметка пула (вымышленные заметки): 2 — прямо по теме, 1 — частично.
- `example_runs.json` — выдача двух вариантов поиска по тем же темам (например, первые 20 путей
  из `semantic_search` для каждого варианта настроек).

Свой эталон храните **вне** публичных репозиториев: в нём ваши реальные запросы и названия заметок.
