# scripts/ — вспомогательные серверные скрипты

## vps-check.sh
Комплексный healthcheck одним прогоном: контейнеры, CouchDB-счётчики, CLI-цикл,
зеркало, индексатор, диск, load. Использовать для ручной проверки и в cron.

## livesync-reconcile-loop.sh
Главный цикл: sync(in) → sync(out) → mirror (ПОСЛЕДНИЙ). Порядок менять нельзя
(runbook-deletion-waves.md). Ставится systemd-сервисом.

## livesync-cli-once.sh
Обёртка одиночного вызова CLI (sync/mirror/rm/pull/push) с таймаутом и проверкой
LevelDB-лока. Используется циклом и для разовых операций (например, дедуп rm).

## README-systemd.md
Как установить CLI-цикл как systemd-сервис (PrivateTmp, restart, автозапуск).

## Заметка о доступе

Скрипты запускаются от рабочего юзера сервера (не root). Если юзеру нужны docker-группа
и доступ к каталогам зеркала/стейджинга — настроить после создания каталогов.
