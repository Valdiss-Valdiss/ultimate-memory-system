# Memory System

**Ultimate memory:** turn private Telegram channels into an E2E-encrypted Obsidian knowledge base — automatically. Every format enriched: photos→OCR descriptions, YouTube→transcripts, PDF→summaries (LLM). Hybrid search: semantic (Qdrant+e5) + graph (neo4j). Multi-device sync, self-healing mirror, 100% self-hosted. Set up by your AI agent. *(Документация на русском ниже.)*

Персональная система памяти на базе Obsidian + Telegram + Docker-стека, которая автоматически:

- принимает **любые посты из ваших Telegram-каналов** (текст, фото, видео, YouTube, документы) и превращает их в аккуратные Markdown-заметки;
- **обогащает** их: OCR/описание фотографий (LLM), транскрипты YouTube-роликов, резюме документов (docling + LLM);
- **раскладывает** заметки по папкам автоматически (triage по конфигу каналов);
- хранит всё в **зашифрованном end-to-end** vault'е (Obsidian LiveSync), синхронизированном между ПК, телефоном и сервером;
- даёт **семантический поиск** по всем заметкам (Qdrant + эмбеддинги);
- переживает аварии: самовосстанавливающееся зеркало, дедупликация, снапшоты, стражи от rate-limit'ов.

│  ai-assistant (опционально)  indexer  watchdog                                  │

        │                ▲                          ▲
        ▼                │                          │
┌─────────────── ПК ─────┴──────────┐    ┌────────── Телефон ──────────┐

## Для кого это

- У вас (или хотите завести) **VPS с Docker** и **компьютер с Obsidian**.
- Требования к серверу: **минимум 8 GB RAM** (проверено живыми замерами),
  рекомендуется **12–16 GB** (запас под пики конвертации и будущий графовый
  слой neo4j), 2–4 CPU, 40–80+ GB SSD. Полный бюджет — vps/README.md.
- Хотите, чтобы всё, что падает в ваши Telegram-каналы, превращалось в структурированную базу знаний.
- **Не технарь?** Это не проблема: система спроектирована так, чтобы её настраивал **ИИ-агент** (Claude Code, Codex, opencode, Cursor и т.п.) по инструкциям из этого репозитория. Ваша роль — дать агенту доступ и отвечать на вопросы.

## Быстрый старт (для не-технического пользователя)

1. Скопируйте эту папку на ваш компьютер.
2. Скажите вашему ИИ-агенту:

> «Прочитай файл AGENTS.md в папке memory-system-public и действуй по нему.
> Цель: развернуть Memory System на моём сервере и ПК. Все шаги и проверки описаны
> в репозитории, ничего не выдумывай, после каждого этапа запускай validate-скрипты.
> Мои данные для входа: [предоставь доступ к VPS / скажи, что его нужно создать]»

3. Агент будет идти по рунбукам (`docs/runbooks/`) и подтверждать каждый этап
   скриптами из `validate/`. Вам останется: завести VPS, открыть Obsidian,
   дать агенту API-ключи Telegram, и принять первые сообщения.

Подробности: [QUICKSTART.md](QUICKSTART.md) — версия для «человека без технических знаний».

## Чем отличается от известных решений

| Решение | Что делает | Чего НЕ делает (и делает Ultimate Memory System) |
|---|---|---|
| **Karpathy LLM Wiki** (и плагины/скиллы на его основе) | LLM по команде «ingest» компилирует источники в вики; Obsidian как IDE | Приём источников **ручной** (юзер сам кладёт файлы и запускает ingest); одна машина — нет синка устройств; нет E2E; принципиально отвергает векторный поиск |
| **mem0 / Letta (MemGPT) / Zep-Graphiti / Cognee** | «память агента»: извлечение фактов из диалогов, временные графы, tiered memory | Это память **диалогов агента**, а не конвейер внешних данных; память хранится открытым текстом (без E2E); нет Telegram-приёма; нет Obsidian/устройств |
| **Obsidian Copilot / Smart Connections / karpathy-wiki-плагин** | чат и поиск внутри Obsidian | нет приёма из Telegram, нет конвейера обогащения вложений (OCR/транскрипты/док-резюме), нет серверной части и мульти-девайс E2E-синка |
| **Khoj** | personal AI с Obsidian | без Telegram-приёма, без E2E, без OCR/транскриптов канальных постов |
| **selfhost-ai (kossakovsky)** | конструктор self-hosted сервисов (n8n, Qdrant, Neo4j…) | нет прикладного конвейера «каналы → обогащённые заметки» — его нужно писать самому; здесь он готов и проверен годом прода |
| **NotebookLM / ChatGPT с файлами** | разовый RAG по загруженным файлам | знание «заново открывается на каждый вопрос», не накапливается; нет владения данными (облако) |

**Чем закрывает Ultimate Memory System:**

1. **Telegram-first capture** — приватные каналы = входящие. Переслал пост с телефона →
   заметка появится в vault на всех устройствах. Автоматически, 24/7, без ручного ingest.
2. **Многослойное авто-обогащение каждого формата**: фото → OCR + LLM-описания;
   YouTube → транскрипты (трёхуровневый каскад); PDF/DOCX → docling + LLM-резюме;
   авто-переименование заметок по содержимому.
3. **Гибридный поиск**: семантический (Qdrant + multilingual-e5) поверх зеркала +
   Obsidian-поиск + запланированный граф neo4j.
4. **E2E-шифрованный multi-device vault** — сервер хранит только шифроблоки.
5. **Прод-надёжность**: self-healing зеркало (mirror-last), дедупликация, защита от
   deletion-волн, стражи rate-limit, снапшоты, перехват stderr — всё описано рунбуками.
6. **Полностью self-hosted**: локальные эмбеддинги (TEI), локальный Telegram Bot API.
7. **AI-agent-first**: ставится и обслуживается ИИ-агентом (validate-скрипты + рунбуки).

## Важно понимать заранее (честные ограничения)

- **Установка требует времени**: Серверная часть — это 9 контейнеров (см. vps/docker-compose.yml), Obsidian-конвейер — тонкие
  настройки плагина LiveSync. ИИ-агент справится, но это не «нажми кнопку»: ожидайте
  несколько сессий работы агента.
- **Платные зависимости**: VPS-хостинг; опционально — LLM-подписка, Deepgram для
  транскриптов видео без субтитров, TranscriptAPI для YouTube.
- **Telegram user-session**: часть конвейера использует вашу пользовательскую сессию
  Telegram (не бота) — это легально и штатно (ваш аккаунт, ваше API), но требует API_ID/API_HASH
  от Telegram и дисциплины rate-limit (стражи включены).
- **Это не коробочный продукт**: это работающий продакшн-код + накопленная
  операционная документация. Ожидайте, что агент будет «вести» систему как живой проект.

## Что нового в v0.1.0-rc2

Редакция про **автономность**: система теперь сама переживает сон ПК, обрыв
сети, смену IP-адреса (VPN) и тихие отказы внешних сервисов — и сама сообщает
о проблеме.

- **Один SSH-канал вместо пачки** (`pc-scripts/vps_ssh.py`): бэкфиллы больше не
  упираются в rate-limit порта 22.
- **Защита от записи в vault при закрытом Obsidian** (`pc-scripts/vault_guard.py`):
  устраняет класс аварий с массовым удалением заметок.
- **Канари здоровья** (`pc-scripts/health_canary.py` + задача «Memory Health
  Canary»): раз в час проверяет всю цепочку и пишет отчёт в заметку
  `Inbox/AI/Status/health.md`.
- **Авто-whitelist SSH** (`vps/scripts/sync-whitelist.sh`): смена VPN-выхода
  больше не ломает служебные подключения.
- **Healthcheck CouchDB «200/401 = жив»**: контейнер перестаёт выглядеть мёртвым
  и не перезапускается внешним autoheal (из-за этого рвался синк).
- **Ротация LLM-ключей**: истёкший ключ не роняет конвейер молча.
- **Репозиторий стал собираемым**: серверные исходники перенесены в `vps/bot/`
  (раньше `Dockerfile` копировал `*.py`, которых в папке не было).
