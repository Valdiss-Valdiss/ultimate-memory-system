# SECURITY.md — ключи, пароли и данные

## Модель секретов

| Секрет | Где хранится | Что открывает | Утечка означает |
|---|---|---|---|
| Ключ SSH (id_ed25519) | только ПК пользователя | вход на сервер (user без root) | доступ к серверу как этот user |
| Root-пароль VPS | хостинг-панель (для консоли) | полный контроль ВМ | полный контроль ВМ |
| API_ID / API_HASH (Telegram) | `.env` на сервере и ПК | приложение Telegram | спуфинг приложения (аккаунт не угоняется) |
| BOT_TOKEN | `.env` на сервере | управление ботом | чтение постов каналов, управление ботом |
| Ключи LLM (LLM_KEY, Deepgram, TranscriptAPI) | `.env` | вызовы сервисов | трата квот |
| **E2E-парольная фраза vault** | **ТОЛЬКО устройства пользователя** | расшифровка vault | чтение всех заметок |

## Железные правила

1. **E2E-парольная фраза никогда не хранится на сервере.** Сервер не должен уметь
   расшифровывать vault. Если увидел passphrase в файлах сервера — инцидент, удаляй.
2. **Значения секретов никогда не печатаются** в логи, чат, отчёты. Проверка наличия —
   только по именам переменных.
3. `.env` — права 600 (только владелец), никогда не коммитится (см. `.gitignore`).
4. Ключ-файлы (SSH, Telegram-сессии) — никогда не копируются в репозиторий,
   облако, переписку. Они не передаются по сети (протокол не пересылает приватный
   материал), но вирус на ПК может их прочитать.
5. Парольный вход SSH на сервере — отключён (только ключи). Root — только через
   хостинг-консоль.

## Что попадает в этот репозиторий

- Код и документация — да.
- `.env.example` с ПОДСТАНОВОЧНЫМИ значениями (`changeme`) — да.
- Реальные `.env`, `channels.json`, `folders.yaml`, `session/`, `state/`, логи — **нет**.
  Все они в `.gitignore`.
- Примеры данных (`channels.example.json`, `folders.example.yaml`) — вымышленные
  значения, без реальных названий каналов и ID.

## Проверка на утечку перед публикацией

```bash
grep -rniE "api_id|api_hash|bot_token|passphrase|t\.me/c/[0-9]" --exclude-dir=.git .
```
Найденные совпадения в коде — это чтение переменных окружения (ок), литеральные
значения — удалить немедленно.

## Аварийный доступ

- Веб-консоль хостингера — вход в ВМ мимо SSH (страховка при поломке SSH).
- Снапшот ВМ — откат состояния целиком (живёт ~1 сутки).
- E2E: если потеряна парольная фраза — данные невосстановимы НИКЕМ. Храните её
  в менеджере паролей.
